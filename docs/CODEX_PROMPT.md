# Codex 向けプロンプト集

このドキュメントは、tui-todo の追加開発を Codex に依頼するときにそのまま使えるテンプレートです。

## ロール定義

- 作業前に `README.md` と `docs/DESIGN.md` を読む。
- 設計原則に反する変更は事前確認する。
- JSON スキーマ互換を維持する。
- ロジック層と UI 層の境界を越えない。

## 標準ワークフロー

1. タスクを 3〜7 項目の TODO に分解
2. 変更ファイルと要点を簡潔に提示
3. 実装
4. `gofmt -l .` / `go vet ./...` / `go test ./...` / `go build ./...` を実行
5. 未検証事項を明記

## 依頼テンプレート

- 機能追加
- バグ修正
- リファクタ

詳細は必要に応じてこのファイルに追記して運用する。
